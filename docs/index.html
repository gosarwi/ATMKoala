Experimental / x86-64 / Freestanding

A small operating system with a complete path from firmware to desktop.

ATMKoala is a freestanding C and assembly operating system for x86-64. It boots with Limine on BIOS and UEFI, enters a custom long-mode kernel, and provides the Exp framebuffer desktop, a text console, a native static libc, VFS, ext2 integration, and a compact TCP stack.

Download the ISOBrowse source

Current system baseline

The mainline ISO uses Limine exclusively. The kernel keeps a Multiboot2 entry contract while Limine supplies BIOS and UEFI hybrid ISO support. Frozen ATMBOOT and ATMUEFI paths remain separate legacy artifacts.

Boot and kernel

Limine v12.6.0, Multiboot2 handoff, custom page tables, IDT, scheduler, kernel heap, and CPL 3 user-process execution.

Native user space

Static ELF64 ET_EXEC programs, task-local descriptors, `int $0x80` system calls, bounded `brk`, a freestanding static libc, and ATMBox Toybox-compatible applets.

Desktop and storage

Exp desktop, terminal, Notepad, Files, Viewer, ArchiveEx, ATA PIO disk discovery, MBR primary-partition inspection, CatFS primary-partition mount/fsck, FAT32, and a read-only ext2 VFS adapter with guarded existing-block writes.

Networking

RTL8139, ARP, IPv4, TCP retransmission, slow start, listener/accept primitives, checksums, windows, and native socket ABI. net drivers reports PCI Ethernet controller state; inventory reaches bridged and multifunction RTL8139 devices.

Process telemetry

Per-task CPU ticks, resident mapped bytes, native FD read/write bytes, and context switches are reported through `ps`, `free`, `iostat`, and related ATMBox applets.

Graphics foundation

Framebuffer and TinyGL-Lite capability reporting is available through gfxinfo, mesa, and atm-box gpuinfo. Exp also has a fixed-point software gears demo. This is not a Mesa, OpenGL, GLX, EGL, Gallium, DRM, or DRI port.

Installer and setup

The dedicated GUI installer selects a timezone preset and hidden root password, then creates one 1 MiB-aligned CatFS MBR partition only after typed ERASE. Press L for its bounded read-only log; the successful journal persists as installer-log. The password is persisted as a salted hash.

Validation and boundary

The Exp desktop has a manual Gregorian Calendar, compact alpha taskbar/title overlays, and clearer menu/radio/battery glyphs. Calendar never claims a live date: RTC/NTP is absent. Full blur compositing is not implemented. net drivers can identify Intel, RTL8168/8125 and virtio-net controllers, but their drivers remain unavailable; USB mass storage, TLS/HTTPS, USB/HID mouse transport, and hardware GPU acceleration are unimplemented.

Build it

The source tree includes the pinned Limine release assets used by the ISO build. The active workflow does not use GRUB.

git clone https://github.com/gosarwi/ATMKoala.git
cd ATMKoala
make all
make iso

Run it

The canonical artifact is atmkoala-OS-v0.9-limine.iso. Use QEMU during development and test the disk installer only on disposable media.

make run
# or
make run-vbe
